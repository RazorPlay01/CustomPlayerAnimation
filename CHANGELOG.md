# 5.5.0
- The crouching animation position has been corrected, as the character was floating approximately 4 pixels.
- A configurable smoothing effect has been added to the lean animation to prevent abrupt changes when rapidly modifying the movement vector.
- The ability to modify the lean effect based on mouse movement has been added.
- A bug has been fixed which sometimes left players in multiplayer with an incorrect lean effect. (They remained inclined despite being still)
